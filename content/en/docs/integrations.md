# Integrations

Asetio is designed to coexist with existing systems. The platform exposes events and integration points to connect physical operations with internal processes.

## API

The API can integrate tenant, user, asset, gateway, tag, alert, and maintenance data with external systems.

## Webhooks

Webhooks can react to relevant events:

- Asset changes.
- Tag readings or state changes.
- Gateway heartbeats.
- Alert creation or updates.
- Maintenance task changes.

## OAuth and identity

The platform includes OAuth integration points to connect external accounts and centralize authentication flows when a tenant requires it.

## Internal events

The backend publishes tenant-aware events to keep dashboards, radar, and operational modules updated in real time.
