# Documentacion de Asetio

Asetio es una plataforma operacional para organizaciones que necesitan mantener trazabilidad sobre activos criticos, su estado en tiempo real, alertas y mantenimiento en terreno.

La documentacion esta organizada para explicar el producto desde tres capas:

- **Producto:** que problema resuelve y para quien existe.
- **Plataforma:** como se organizan tenants, usuarios, activos, fuentes de captura y workflows.
- **Captura de estado:** como las lecturas de campo entran al sistema y se transforman en estados accionables.
